Is this affiliated with LeetCode?

No. Wrapped Live is an independent project. It reads the same public profile data anyone can see on leetcode.com.

How fresh are the stats?

Free cards refresh every 4 hours and Pro cards every 30 minutes. GitHub also caches README images on its end, so a README can lag a little behind your site.

Does my profile need to be public?

Yes. Cards use your public LeetCode profile, so no login or API key is involved.

What happens if LeetCode is down?

Your card keeps showing your last known stats until LeetCode responds again. It never breaks into an empty image.
